The silent ones

pm grant

For a permission the app never declared: exit 0, no output on any stream, and nothing granted.

simctl privacy

Accepts a bundle id for an app that is not installed, and does nothing. Successfully.

adb uninstall

Reports Success when all it removed was the updates to a system app. The app is still there.

Rule 02

Read the state back. dumpsys package, not the command's opinion of itself.

Where the platform cannot report state back — iOS privacy is write-only — check the precondition before the write instead.
