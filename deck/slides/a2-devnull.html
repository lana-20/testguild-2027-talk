The one that cost most

mobium back >/dev/null 2>&1

there is no “back” command, and there never has been

The shell printed unknown command into /dev/null. The screen did not move. The next step was misdiagnosed as a scrolling problem for far longer than I want to admit — and that redirect was hiding a missing feature, not a failing call.

“2>/dev/null” is a claim that you already know what a failure there means.

The punchline is that it hid a missing feature. The tool could not press back at all, and this redirect delayed finding that out.
