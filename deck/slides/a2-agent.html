An error message is an instruction an agent obeys unconditionally.

unknown ref text=Charles Babbage — run app_map again

The refusal was correct

Inside a WebView the map matches CSS selectors. There is nothing for a text locator to resolve against.

The advice was impossible

Re-mapping can never help — the ref was never stale. Followed literally, it loops forever.

A wrong remedy is worse than no remedy, because it gets obeyed. When you write an error, check that doing what it says could actually fix it.

This is the strongest agentic beat in the deck. A human gives up on bad advice eventually; an agent does not.
