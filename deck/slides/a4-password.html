Aegis, screen one

My tool printed passwords in plaintext.

Android marks the node password="true" and puts the typed value in its text attribute.

I parsed the flag. I read it nowhere.

Every path that surfaces node text now redacts: the length is kept, the value dropped. And the regression fixture's password value is literally PASSWORD-MUST-NOT-APPEAR — so a leak names itself in the failure output.

The single statement slide in the deck. Do not rush it and do not soften it. The fixture naming trick is the practical gift — say it slowly.
